## 一、工具链要求

| 工具 | 版本 | 是否必需 | 用途 |
|---|---|---|---|
| Rust（stable） | ≥ 1.75，建议最新稳定版 | ✅ 必需 | workspace 编译（edition 2021） |
| Cargo | 随 Rust | ✅ 必需 | 构建 / 依赖管理 |
| Tauri CLI v2 | 2.x | ✅ 运行/打包时必需 | `cargo tauri dev` / `build` |
| **Node.js** | ≥ 18 | ⛔ **不必需** | 前端为零构建静态文件（`frontendDist: ../ui`），无 npm 依赖 |
| **Python** | ≥ 3.9 | ⚠️ 仅本地引擎 | 云 ASR 引擎**零 Python 依赖** |
| pkg-config | 任意 | Linux 必需 | 探测 WebKitGTK / ALSA |

> 说明：`beforeDevCommand` / `beforeBuildCommand` 均为空，`ui/` 直接作为静态资源目录，因此**不需要 Node、pnpm、前端构建步骤**。只有当你改用 npm 版 `@tauri-apps/cli` 或引入前端框架时才需要 Node。

### 各平台系统依赖

**Linux（Ubuntu / Debian）**

```bash
sudo apt-get update
sudo apt-get install -y \
  build-essential pkg-config \
  libwebkit2gtk-4.1-dev libgtk-3-dev \
  libayatana-appindicator3-dev librsvg2-dev \
  libasound2-dev libssl-dev patchelf
```

验证：

```bash
pkg-config --exists webkit2gtk-4.1 && echo "webkit2gtk-4.1 OK"
pkg-config --exists alsa && echo "alsa OK"
which patchelf
```

**macOS**

```bash
xcode-select --install
```

WebKit 由系统 WKWebView 提供，无需 Homebrew 依赖。

**Windows**

- Visual Studio 2022「使用 C++ 的桌面开发」生成工具（MSVC linker）
- WebView2 Runtime（Windows 11 已内置，旧系统需单独安装）
- 建议启用「立体声混音」以使用系统内录（见 App 内「查看内录帮助」）

## 二、获取代码

```bash
git clone https://github.com/xiaopengs/moonshine-meeting-assistant.git
cd moonshine-meeting-assistant
```

目录要点：

```
Cargo.toml              # workspace = crates/core + src-tauri
crates/core/            # moonshine-core（UI 无关，含本地/云端引擎）
src-tauri/              # Tauri 2 应用壳 + tauri.conf.json
ui/                     # 静态前端（无需构建）
python/                 # 本地引擎服务（engine_service.py）
doc/                    # 文档
assets/                 # 图标 + 架构图
```

## 三、分层编译（推荐先跑）

**1. 只编译核心库**（最快，不需要 Tauri 系统库，含三家云 ASR 签名/WebSocket 代码）

```bash
cargo check -p moonshine-core
```

**2. 编译整个 workspace**（需要完整的 Tauri 系统依赖）

```bash
cargo check --workspace
```

**3. 代码质量检查**

```bash
cargo clippy --workspace
```

**4. 前端语法检查**（可选）

```bash
node --check ui/main.js     # 若本机有 Node；无 Node 可跳过
```

> 首次编译会拉取 Tauri / tokio / tungstenite 等依赖，耗时数分钟；`target/` 已加入 `.gitignore`。

## 四、安装 Python 引擎依赖（仅本地引擎）

```bash
pip install -r python/requirements.txt
```

`requirements.txt` 默认启用 `numpy` + `faster-whisper`；`moonshine-voice`、`funasr` 为注释状态，按需取消注释安装。

**云 ASR 用户可完全跳过本节**：火山/腾讯/阿里均为 Rust 原生实现，不启动 Python 子进程。

模型首次使用时自动下载（默认 faster-whisper `large-v3-turbo`）。国内网络可设置镜像：

```bash
export HF_ENDPOINT=https://hf-mirror.com     # Linux / macOS
# Windows PowerShell: $env:HF_ENDPOINT="https://hf-mirror.com"
```

---

## 五、安装 Tauri CLI 并运行

```bash
cargo install tauri-cli --version "^2" --locked
```

**开发运行**（热重载前端静态资源）

```bash
cargo tauri dev
```

**编译验证（不打包）**

```bash
cargo build --release
```

**打包发布**

```bash
cargo tauri build
# 仅打指定格式：
cargo tauri build --bundles nsis        # Windows
cargo tauri build --bundles dmg         # macOS
cargo tauri build --bundles appimage    # Linux
```

产物位于 `target/release/bundle/`，详见 [部署指导](./部署指导.md)。

## 六、关键配置说明

| 配置 | 位置 | 说明 |
|---|---|---|
| `frontendDist` | `src-tauri/tauri.conf.json` | `../ui`，静态前端目录 |
| `bundle.resources` | `src-tauri/tauri.conf.json` | 随包携带 `python/engine_service.py` 与 `requirements.txt` |
| `capabilities/default.json` | `src-tauri/capabilities/` | Tauri 2 权限（`core:default` + `dialog:default`） |
| `MOONSHINE_ENGINE_SCRIPT` | 环境变量 | 覆盖本地引擎脚本路径，优先级最高 |
| `asr-settings.json` | `app_config_dir()` | 云 ASR 凭证（本机保存） |
| `HF_ENDPOINT` | 环境变量 | Hugging Face 镜像（本地引擎下载模型） |

**引擎脚本查找顺序**（`default_engine_script()`）：

1. 环境变量 `MOONSHINE_ENGINE_SCRIPT`；
2. 当前工作目录下 `python/engine_service.py`（开发模式）；
3. 可执行文件同目录及 `resources/` 子目录下的 `python/engine_service.py`（安装后）。

如自定义部署路径，直接设置环境变量最稳妥：

```bash
export MOONSHINE_ENGINE_SCRIPT=/opt/moonshine/python/engine_service.py
```

## 七、常见错误排查

| 报错 | 原因 | 解决 |
|---|---|---|
| `Package webkit2gtk-4.1 was not found` | Linux 缺 WebKitGTK | 执行第一节 apt 安装；或仅 `cargo check -p moonshine-core` 跳过 |
| `Could not find alsa` / `alsa-sys` 失败 | 缺 ALSA 开发库 | `sudo apt install libasound2-dev` |
| `linker 'cc' not found` | 缺编译工具链 | Linux 装 `build-essential`；macOS 装 Xcode CLT |
| `link.exe` 找不到（Windows） | 缺 MSVC | 安装 VS 2022 C++ 生成工具 |
| `patchelf: command not found` | Linux 打包 AppImage 需要 | `sudo apt install patchelf` |
| `tauri: command not found` | 未装 CLI | `cargo install tauri-cli --version "^2" --locked` |
| 运行时提示「找不到 engine_service.py」 | 打包后工作目录变化 | 设置 `MOONSHINE_ENGINE_SCRIPT`，或确认 `bundle.resources` 生效 |
| `pip` 依赖与 Python 版本冲突 | 多版本 Python 共存 | App 通过 `python3`（Windows `python`）调用，确保该命令指向已装依赖的解释器 |
| 模型下载超时 | 网络 | 设置 `HF_ENDPOINT` 镜像，或预置模型到缓存目录 |
| cargo 拉依赖超时 | 网络抖动 | 重试；或配置 crates.io 镜像 |
| 设备列表为空 / 无内录设备 | 系统权限或设备未启用 | 检查麦克风权限；Windows 启用「立体声混音」，macOS 需虚拟声卡 |
