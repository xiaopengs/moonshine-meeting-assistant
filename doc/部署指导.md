## 一、选择部署形态

| 模式 | 引擎 | 需要 Python/模型 | 出网 | 隐私 | 适用 |
|---|---|---|---|---|---|
| **A 纯本地**（默认） | faster-whisper / moonshine / FunASR | ✅ 需要 | 仅首次下载模型 | 音频零上传 | 涉密会议、内网 |
| **B 云 ASR（BYOK）** | 火山 / 腾讯 / 阿里 | ❌ 不需要 | ✅ 需实时出网 | 音频上传至所选厂商 | 轻量部署、低配机、免运维 |
| **C 混合** | 按会议切换 | 可选 | 可选 | 按需选择 | 日常 + 敏感会议并存 |

> 切换方式：侧栏「转写引擎」下拉，无需重装、无需重启。云引擎凭证配置见 [接入指导](./接入指导.md)。

## 二、打包

```bash
cargo install tauri-cli --version "^2" --locked
cargo tauri build
```

### 各平台产物

| 平台 | 产物 | 输出目录 |
|---|---|---|
| Windows | NSIS `.exe` 安装器 / MSI | `target/release/bundle/nsis/`、`.../msi/` |
| macOS | `.dmg` / `.app` | `target/release/bundle/dmg/`、`.../macos/` |
| Linux | `.AppImage` / `.deb` / `.rpm` | `target/release/bundle/appimage/`、`.../deb/` |

配置文件 `src-tauri/tauri.conf.json`：`identifier` 为 `com.moonshine.meeting-assistant`，图标取自 `src-tauri/icons/`。

### 随包资源（`bundle.resources`）

打包时会把以下文件复制到应用资源目录，供**本地引擎**使用：

- `python/engine_service.py` — 多引擎 JSON 协议服务
- `python/requirements.txt` — 终端用户安装依赖用

> 云 ASR 引擎完全不依赖这些文件，B 模式可忽略。

### 发布注意事项

- **macOS**：分发前需 Developer ID 签名 + 公证（`notarize`），否则 Gatekeeper 会拦截；Tauri 打包可用 `APPLE_*` 环境变量配置。
- **Windows**：建议代码签名证书，避免 SmartScreen 警告；WebView2 Runtime 在 Win11 内置，旧系统需随安装器分发。
- **Linux**：AppImage 依赖 `patchelf`（编译机需安装）；deb/rpm 需声明 `libwebkit2gtk-4.1-0`、`libasound2` 等运行库依赖。
- 版本号统一在根 `Cargo.toml` 的 `[workspace.package] version` 与 `tauri.conf.json` 的 `version` 维护。

## 三、终端用户安装清单

### A 纯本地模式

1. 安装应用。
2. 安装 **Python ≥ 3.9**，并确保命令行 `python3`（Windows 为 `python`）可用。
3. 安装引擎依赖：`pip install -r python/requirements.txt`（文件随包在资源目录，也可用仓库副本）。
4. 首次录制会自动下载模型（数百 MB～1.5 GB）；内网环境请**预先下载模型并放入缓存**，或设置 `HF_ENDPOINT` 镜像。
5. 选择设备 → 开始录制。

### B 云 ASR 模式

1. 安装应用（**无需 Python、无需模型**）。
2. 按 [接入指导](./接入指导.md) 开通服务商并获取 Key。
3. 「🔑 云 ASR 凭证设置」→ 填 Key → 保存 →「测试连接」。
4. 选择设备 → 开始录制。

### 系统内录（双路采集）

| 平台 | 要求 |
|---|---|
| Windows | 启用「立体声混音」（声音控制面板 → 录制 → 显示禁用设备 → 启用）；App 内有图文引导 |
| macOS | 系统不原生提供 loopback，需安装虚拟声卡（BlackHole / Loopback / Soundflower）并创建多输出设备 |
| Linux | PulseAudio/PipeWire 的 `monitor of sink` 设备；App 会自动标记为 ⭐ |

> 若无可用内录设备，可关闭「双路同时采集」，仅用麦克风单路工作。

## 四、运行目录与数据位置

| 内容 | 位置 | 说明 |
|---|---|---|
| 可执行文件 | 安装目录 | Tauri 应用主体 |
| 引擎脚本 | 资源目录 `python/engine_service.py` | 由 `bundle.resources` 复制 |
| 云 ASR 凭证 | `app_config_dir()/asr-settings.json` | 本机保存，不随包分发 |
| 导出文件 | 用户选择路径 | MD / SRT / TXT |
| 模型缓存 | Hugging Face 缓存目录 | 本地引擎首次下载 |
| 运行日志 | App 内「日志」面板 | 不写磁盘，含 `[ERROR]` 前缀便于排查 |

**引擎脚本定位顺序**（见 `src-tauri/src/lib.rs::default_engine_script()`）：

1. 环境变量 `MOONSHINE_ENGINE_SCRIPT`（自定义部署优先用这个）；
2. 当前工作目录下的 `python/engine_service.py`（开发模式）；
3. 可执行文件同目录及 `resources/` 下的候选路径（安装后）。

如把 Python 服务部署到独立目录：

```bash
# Linux / macOS
export MOONSHINE_ENGINE_SCRIPT=/opt/moonshine/python/engine_service.py
```

## 五、离线 / 内网部署

| 需求 | 做法 |
|---|---|
| 完全离线（A 模式） | 预装 Python 依赖 + 预置模型权重；断网可用；云引擎不可用 |
| 内网 + 云 ASR（B 模式） | 放行 WebSocket(443) 到下列域名 |
| 企业代理 | 需支持 WebSocket 升级；`ureq`（阿里云 CreateToken）走 HTTPS 代理环境变量 |

**云 ASR 出网域名**

| 服务商 | 域名 |
|---|---|
| 火山引擎 | `openspeech.bytedance.com` |
| 腾讯云 | `asr.cloud.tencent.com` |
| 阿里云 | `nls-meta.cn-shanghai.aliyuncs.com`、`nls-gateway-cn-shanghai.aliyuncs.com` |

> 双路采集会建立 **2 个并发 WebSocket 会话**，请按并发配额规划（腾讯默认 20～50 路、阿里试用版 2 路）。

## 六、升级与回滚

- 覆盖安装即可升级；`asr-settings.json` 位于用户配置目录，**不会被安装包覆盖**。
- 升级前建议备份配置目录与导出目录。
- 回滚：安装旧版本安装包；凭证 JSON 结构向下兼容（`RemoteCredentials` 三个可选服务商字段）。
- 若自定义了 `MOONSHINE_ENGINE_SCRIPT`，升级后重新确认路径仍有效。

## 七、安全与合规

- **BYOK 凭证**由终端用户自行保管；企业分发时不要预置主账号 AK，使用 RAM 子账号最小权限。
- **音频流向**：A 模式不出网；B 模式仅上传 16 kHz PCM 到所选厂商，转写文本、摘要、导出文件仍留本机。
- **摘要端点**默认 `http://localhost:11434`（本地 Ollama）；若改为云端 LLM，需额外评估文本出网合规。
- **模型许可**：faster-whisper / moonshine / FunASR 及其权重遵循各自许可证，商用前逐项审计。
- **日志**：App 内日志不落盘，但错误可能包含云厂商返回的鉴权提示，截图外发前注意脱敏。

## 八、上线验收清单

- [ ] 目标机器完成打包安装，应用可启动
- [ ] 设备列表可枚举出麦克风（与内录设备）
- [ ] A 模式：Python 依赖就绪，30 秒录音字幕正常
- [ ] B 模式：三家至少一家「测试连接」通过，30 秒录音字幕正常
- [ ] 双路采集可区分「麦克风 / 系统内录」说话人
- [ ] 导出 MD / SRT / TXT 含时间戳与说话人标记
- [ ] AI 摘要（本地 Ollama）可用或已明确关闭
- [ ] 长会（≥ 1 小时）内存稳定、无断流
- [ ] 内网/代理场景出网白名单已放行
- [ ] 凭证文件权限与备份策略已确认
- [ ] 三家云 ASR 真机联调已完成（当前版本尚未在真机验证）

> **已知限制**：本项目已在 Linux 沙箱完成 `cargo check` / `clippy` 编译级验证，但**尚未在 Windows/macOS 真机打包、未用真实云 Key 联调**。首次正式部署请按上表逐项验收。
