# 云 ASR 接入指导

> 版本：v2.0.0 · 更新：2026-11-05
> 适用：Moonshine 会议助手「云端 ASR（BYOK）」
> 相关：[架构设计](./ARCHITECTURE.md) · [本地编译指导](./本地编译指导.md) · [部署指导](./部署指导.md)

## 一、总览

云端 ASR 采用 **BYOK（Bring Your Own Key）** 模式：不内置任何厂商密钥，由使用者在三家云控制台自行开通、创建凭证，填入 App 即可使用。云端引擎为 **Rust 原生 WebSocket 接入**，无需安装 Python、无需下载模型。

**接入四步**

| 步骤 | 操作 | 位置 |
|---|---|---|
| 1 | 开通语音识别服务、创建应用/项目 | 各家云控制台 |
| 2 | 获取凭证（Key） | 各家控制台密钥页 |
| 3 | 填入 App 并保存 | 侧栏「🔑 云 ASR 凭证设置」 |
| 4 | 验证 | 设置弹窗「测试连接」 |

**凭证字段总表**（与 `get_asr_providers()` 元数据严格对应）

| 服务商 | 字段（前端） | 控制台对应 | 是否必填 |
|---|---|---|---|
| 火山引擎 | `accessKeyId` | AccessKey ID（AK） | ✅ |
| 火山引擎 | `secretKey` | Secret AccessKey（SK） | ✅ |
| 火山引擎 | `appId` | APP ID（应用 ID） | ✅ |
| 腾讯云 | `appId` | AppID | ✅ |
| 腾讯云 | `secretId` | SecretId | ✅ |
| 腾讯云 | `secretKey` | SecretKey | ✅ |
| 阿里云 | `accessKeyId` | AccessKey ID | ✅ |
| 阿里云 | `accessKeySecret` | AccessKey Secret | ✅ |
| 阿里云 | `appKey` | 项目 Appkey | ✅ |

**凭证存储**：`asr-settings.json`，位于 Tauri `app_config_dir()`（常见路径：Windows `%APPDATA%\com.moonshine.meeting-assistant\`、macOS `~/Library/Application Support/com.moonshine.meeting-assistant/`、Linux `~/.config/com.moonshine.meeting-assistant/`）。文件仅写入本机，**不会上传、不会随会议记录导出**。

> ⚠️ 隐私边界：选择云引擎后，麦克风/系统内录的 **16 kHz 单声道 PCM 音频会实时上传**到所选服务商。本地引擎则全程零上传。请按会议密级选择引擎。

## 二、火山引擎（豆包流式语音识别）

| 项 | 值 |
|---|---|
| 控制台 | <https://console.volcengine.com/speech/app> |
| 官方文档 | <https://www.volcengine.com/docs/6561/1354869> |
| 代码端点 | `wss://openspeech.bytedance.com/api/v3/sauc/bigmodel` |
| 鉴权实现 | URL 查询参数 + HMAC-SHA256 签名 |
| 实现文件 | `crates/core/src/engine/remote/volcengine.rs` |

### 开通与取 Key

1. 注册/登录火山引擎账号，完成**实名认证**（个人可扫码刷脸）。
2. 进入[语音技术控制台 → 应用管理](https://console.volcengine.com/speech/app)，点击**创建应用**。
3. 勾选「**流式语音识别大模型**」（豆包流式语音识别模型 2.0，小时版按使用时长计费，个人试用通常有免费额度）。
4. 创建完成后，在应用详情页或「API 服务中心」查看并复制 **APP ID** 与 **Access Token**。
5. 若控制台提供的是 **AK / SK**（账户级 AccessKey ID / Secret AccessKey），在[访问控制 → API 访问密钥](https://console.volcengine.com/iam/keymanage)获取。

### ⚠️ 新旧控制台鉴权差异（重要）

| 控制台版本 | 官方鉴权 | 所需凭证 |
|---|---|---|
| 旧版 | WebSocket Header：`X-Api-App-Key` + `X-Api-Access-Key` + `X-Api-Resource-Id` | APP ID + Access Token |
| 新版 | WebSocket Header：`X-Api-Key` + `X-Api-Resource-Id` | App Key（单 Key） |
| **本项目当前实现** | URL：`access_key_id` / `app_id` / `timestamp` / `signature`（HMAC-SHA256） | AK + SK + APP ID |

当前实现参考 `coretab/CoreTab/js/asr/asr-volcengine.js`，采用 **URL 签名**方式，`init` 消息也是 v1 风格（`app.appid` / `clusterid` / `token`）。若你的控制台只提供 **App ID + Access Token**（无 AK/SK），需要按官方 v3 协议改造：

1. 在 `engine/remote/mod.rs` 的 `ProviderSpec` 增加 `headers: Vec<(String, String)>`；
2. 在 `run_session()` 中改用 `IntoClientRequest` 构造带 Header 的握手请求；
3. 在 `volcengine.rs::build_spec()` 填入 `X-Api-App-Key` / `X-Api-Access-Key` / `X-Api-Resource-Id`（2.0 小时版为 `volc.seedasr.sauc.duration`）；
4. 按 v3 协议调整首包格式与结果解析。

> 建议：先用「测试连接」确认当前签名方式是否与你的凭证体系匹配；若返回鉴权错误，优先核对上述版本差异。

### 模型

| 预设 ID | 说明 |
|---|---|
| `bigmodel` | 豆包流式语音识别模型 2.0（中文，默认） |
| `bigmodel_en` | 豆包流式（英语） |

主界面「模型」输入框可手动填写，值会透传到 `request.model`。

## 三、腾讯云（实时语音识别 V2 / 大模型）

| 项 | 值 |
|---|---|
| 控制台 | <https://console.cloud.tencent.com/asr> |
| 官方文档 | <https://cloud.tencent.com/document/product/1093/131127> |
| 代码端点 | `wss://asr.cloud.tencent.com/asr/v2/{appid}` |
| 鉴权实现 | HMAC-SHA1 签名（字典序参数 + Base64） |
| 实现文件 | `crates/core/src/engine/remote/tencent.rs` |

### 开通与取 Key

1. 在[语音识别控制台](https://console.cloud.tencent.com/asr)**开通服务**（新用户有免费额度）。
2. 进入 **API 密钥管理** → **新建密钥**，生成 **AppID、SecretId、SecretKey**。
3. 三者填入设置弹窗对应字段；`AppID` 同时用于拼接 WebSocket 路径。

### 模型参数

`engine_model_type` 决定识别引擎。官方 V2 常用值（以[官方参数表](https://cloud.tencent.com/document/product/1093/131127)为准）：

| 值 | 说明 |
|---|---|
| `16k_zh_en` | 中英大模型 + 多方言（会议首选） |
| `16k_zh_large` | 大模型增强版 |
| `16k_zh` | 中文普通话通用 |
| `16k_multi_lang` | 多语种大模型 |

App 下拉预设 `16k_zh_en_2.0` / `16k_zh_en_speaker_2.0` 为历史命名；**建议在主界面「模型」框手动填写上表官方值**（该值原样透传到 `engine_model_type`）。说话人分离需选用支持声纹聚类的 V2 引擎，并在控制台确认已开通。

> 代码中的 `legacy_model()` 仅对 `""` 补默认值、对两个历史值做兼容映射，其余值一律透传；如需启用说话人分离，请同步核对 `tencent.rs` 的模型映射逻辑。

### 音频与并发

- 采样率 16 kHz / 16 bit / 单声道 PCM（与本项目 `cpal` 采集一致）。
- 建议 1:1 实时率发送；发包间隔 > 6 秒会被服务端断开。
- 单账号默认并发 20～50 路，双路采集会占用 **2 路并发**。

## 四、阿里云（智能语音交互 NLS）

| 项 | 值 |
|---|---|
| 控制台 | <https://nls-portal.console.aliyun.com/> |
| 官方文档 | <https://help.aliyun.com/knowledge_detail/72214.html> |
| 代码端点 | `wss://nls-gateway-cn-shanghai.aliyuncs.com/ws/v1?token=...` |
| Token | `CreateToken`（RPC POP 签名，`nls-meta.cn-shanghai.aliyuncs.com`）|
| 实现文件 | `crates/core/src/engine/remote/alicloud.rs` |

### 开通与取 Key

1. 开通「智能语音交互」服务（免费试用版通常 3 个月、2 路并发）。
2. 创建 **AccessKey**：推荐用 RAM 用户并授予 `AliyunNLSFullAccess`（最小权限），保存 **AccessKey ID / AccessKey Secret**（Secret 仅创建时可见）。
3. 进入控制台 **全部项目 → 创建项目**（类型选「仅语音识别」即可），复制项目 **Appkey**。
4. 在 **项目功能配置 → 语音识别 (ASR)** 中选择 **16 kHz 非电话场景模型**，点击「确认使用」。

> Appkey 用于标识项目，**与 AccessKey 不是一回事**；换项目/换 Appkey 不需要更换 AccessKey。App 会自动调用 `CreateToken` 换取临时 Token，无需手工处理。

### ⚠️ 模型绑定说明

阿里云模型**主要由项目（Appkey）绑定**：控制台「项目功能配置」里选的模型决定默认识别模型，通常不支持通过 API 参数随意切换。当前实现会把主界面「模型」值透传到 `StartTranscription` 的 `model` 字段；若返回模型不合法，请：

- 在控制台确认项目已配置 16 kHz 实时识别模型；
- 或把「模型」改为控制台/文档给出的有效名称；
- 需要不同模型时，创建多个项目并使用各自的 Appkey。

地域当前固定 `cn-shanghai`；使用其他地域需修改 `alicloud.rs` 的 `RegionId` 与网关域名。

## 五、在 App 中完成配置

1. 侧栏「**转写引擎**」下拉选择云引擎（火山 / 腾讯 / 阿里）。
2. 出现「**🔑 云 ASR 凭证设置**」按钮 → 点击打开设置弹窗。
3. 选择服务商 → 按字段填写 Key → 选择/确认模型。
4. 点击「**保存**」（写入本机 `asr-settings.json`）。
5. 点击「**测试连接**」，确认凭证有效。
6. 回到主界面，确认「模型」与「语言」后点击「开始录制」。

**「测试连接」判定逻辑**

| 服务商 | 验证方式 | 成功判定 |
|---|---|---|
| 火山引擎 | 发起 WebSocket 握手（URL 签名） | 服务端返回 `code=1000` |
| 腾讯云 | 发起 WebSocket 握手（签名 URL） | 首条消息 `code=0` |
| 阿里云 | 调用 `CreateToken` | 成功取得 Token（不建 WebSocket） |

> 「测试连接」会先保存当前填写的凭证，再验证；失败信息直接显示在弹窗底部。

## 六、常见错误排查

| 现象 | 常见原因 | 处理 |
|---|---|---|
| `凭证不完整：需要 …` | 有字段留空 | 补齐三个必填字段 |
| 签名/鉴权失败（4xx、code≠0） | Key 复制含空格、AK/SK 与 AppID 不匹配、控制台版本差异 | 重新复制；核对第二/三/四节的版本差异 |
| 时间戳过期 | 本机系统时间与标准时间偏差过大 | 校准系统时间（NTP） |
| `engine_model_type` 无效 | 模型名与控制台/文档不一致 | 主界面「模型」改填官方值 |
| 阿里云「模型不合法」 | 项目未配置 16 kHz 模型 / Appkey 与模型不匹配 | 控制台项目功能配置中确认模型 |
| 连接超时 / 被重置 | 网络代理、企业防火墙、WebSocket 被拦截 | 检查出网白名单（见[部署指导](./部署指导.md)） |
| 有连接但无字幕 | 未选择音频设备 / VAD 阈值过高 / 静音 | 检查设备下拉与「启用 VAD」开关 |
| 欠费/额度耗尽 | 免费额度用完 | 控制台查看计费与用量 |

**出网域名白名单**：`openspeech.bytedance.com`、`asr.cloud.tencent.com`、`nls-meta.cn-shanghai.aliyuncs.com`、`nls-gateway-cn-shanghai.aliyuncs.com`。

## 八、安全与合规

- **最小权限**：优先使用 RAM 子账号/子用户密钥，仅授予语音识别权限，勿用主账号 AK。
- **勿入库**：`asr-settings.json` 已在 `.gitignore` 范畴之外的用户配置目录，**不要提交到仓库、不要截图外发**。
- **计费**：三家均按识别时长/并发计费，双路采集会同时开启 2 路会话；长期会议建议关注用量告警。
- **数据流向**：云引擎仅上传音频流，转写结果、摘要、导出文件仍留在本机；摘要默认走本地 Ollama。
- **模型许可**：本地引擎及模型权重遵循各自许可证，商用前逐项审计。

> **已知限制**：三家云 ASR 的签名与握手逻辑已按官方协议与 `coretab` 实现内置，但**尚未在真机用真实 Key 联调**（开发环境无云账号与音频设备）。上线前请务必用「测试连接」+ 一段 30 秒真实会议音频做端到端验证，并按上文「版本差异」核对所用控制台版本。
